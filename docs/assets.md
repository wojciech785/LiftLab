# Assets (DAM)

All published visuals need meaningful alt text (en + cs) and a `rightsSource`.
The web app's `Media` component refuses to render an image without both.

## Upload path

Direct uploads to Hygraph's S3 bucket are blocked from Claude's sandboxes, so
assets are imported **by URL**: commit the file to this public repo, push, then

```graphql
mutation { createAsset(data:{
  uploadUrl:"https://raw.githubusercontent.com/wojciech785/LiftLab/main/assets/…",
  altText:"…", rightsSource:"…",
  localizations:{ create:[{ locale: cs, data:{ altText:"…" } }] }
}) { id } }
```

**Assets are localized per file.** Creating the `cs` localization with only
`altText` leaves that locale without a file (`ASSET_CREATE_PENDING`), and
publishing fails with "You tried to publish a non complete asset". Give each
locale its file — at create time, or afterwards with:

```graphql
mutation { updateAsset(where:{id:$id}, data:{ localizations:{ update:[{ locale: cs,
  data:{ reUpload: true, uploadUrl:"https://raw.githubusercontent.com/…" } }] } }) { id } }
```

Then connect the asset to its entry and publish both (`locales:[en, cs]`,
`publishBase:true`): assets first, then the entries that reference them.

## Muscle-group illustrations

Source: `assets/muscle-groups/<slug>.svg`, generated by
`node scripts/assets/build-muscle-illustrations.mjs` (front + back silhouettes,
one highlighted region). Original artwork created for Lift Lab with AI
assistance, released under CC0 — no third-party rights. A simple abstract body
diagram, as the SDD suggests before any 3D model; not anatomically precise.

Imported, linked and published on 2026-11-10 (en + cs) for all seven published
muscle groups; `mcp-test-quadriceps` (draft fixture) has none. Geometry lives in `apps/web/src/components/body-map/geometry.json` and is shared
with the interactive web body map. (Regenerating changed the SVG markup to
paths only; the result is visually identical to the copies already in Hygraph.)

Linked to `MuscleGroup.illustration`; `GET /api/muscle-groups` returns it and
the exercise library shows it only as a fallback for a selected group the body
map cannot draw (unknown `meshId`).

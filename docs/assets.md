# Assets (DAM)

All published visuals need meaningful alt text (en + cs) and a `rightsSource`.
The web app's `Media` component refuses to render an image without both.

## Upload path

Direct uploads to Hygraph's S3 bucket are blocked from Claude's sandboxes, so
assets are imported **by URL**: commit the file to this public repo, push, then

```graphql
mutation { createAsset(data:{
  uploadUrl:"https://raw.githubusercontent.com/wojciech785/LiftLab/main/assets/…",
  altText:"…", rightsSource:"…",
  localizations:{ create:[{ locale: cs, data:{ altText:"…" } }] }
}) { id } }
```

Then connect the asset to its entry and publish both (`locales:[en, cs]`).

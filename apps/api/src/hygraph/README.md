# GraphQL contracts

`operations/*.graphql` contains the nine application queries and mutations.
`schema.graphql` is a sorted schema snapshot fetched from Hygraph introspection.
`generated/operations.ts` is generated by GraphQL Code Generator; do not edit it.
The snapshot contains schema metadata only, not content entries or credentials.

From the repository root:

```sh
# Requires the existing server-only Content API read credentials in apps/api/.env.
npm run hygraph:schema:refresh

# Offline: validate every operation against the snapshot and regenerate types.
npm run codegen

# Offline: validate operations and fail if generated output is stale.
npm run codegen:check

# Also runs negative compile-time checks in test/type-contracts.ts.
npm run typecheck
```

After applying a schema migration, refresh the snapshot, regenerate, and review
both diffs. Commit the operation files, schema snapshot, and generated output
together. A new environment should first receive migrations 001–005, then have
its snapshot refreshed. Builds/tests use the committed output and do not contact
Hygraph. Checking freshness compares against the local snapshot; detecting a
remote schema change requires the explicit refresh step.

Services pass generated `TypedDocumentNode` values to `HygraphService.query`
or `.mutate`. The document determines response and variable types; `NoInfer`
prevents a wrongly shaped variables object from weakening that contract. The
transport serializes the document with GraphQL's `print` before the HTTP call.
REST DTOs remain separate so frontend contracts do not expose CMS-specific types.

RichTextAST is mapped to the shared RichContent type. Unmapped/custom JSON is
unknown rather than any. Article block types are discriminated by the explicitly
selected `__typename`. Nullable relations and CMS enums come from the snapshot.

The operations plugin in the installed Codegen version emits its referenced
input/enum types directly. Combining it with the standalone typescript plugin
in the same output would duplicate those declarations.

Reference: [The Guild TypedDocumentNode documentation](https://the-guild.dev/graphql/codegen/plugins/typescript/typed-document-node).
